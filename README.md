# 彩美专机店 · 企业官网

专业花边打折加工工厂官方网站（静态站点，单页）。

## 预览

直接用浏览器打开 `index.html` 即可预览。

## 目录结构

```
.
├── index.html      # 网站主页（GitHub Pages 入口文件，必须叫这个名字）
├── README.md       # 项目说明
└── .nojekyll       # 告诉 GitHub Pages 不要用 Jekyll 处理，避免静态资源 404
```

## 上线前需要替换的占位信息

| 位置 | 占位内容 | 说明 |
| --- | --- | --- |
| 顶部通栏 / 导航 / 页脚 | `138-0000-0000` | 替换为真实联系电话 |
| 联系方式板块 | `caimei-lace` | 替换为真实微信号 |
| 联系我们板块 | 广州花都区某某工业区8栋 | 替换为真实工厂地址 |
| 页脚 | 粤ICP备XXXXXXXX号 | 替换为真实备案号（国内服务器才需要） |
| 产品展示 | SVG 装饰花边图案 | 建议替换为实拍样品照片 |

## 技术说明

- 纯静态单文件站点，无任何构建步骤、无外部依赖
- 花边图案、工厂插画均为内联 SVG 绘制，不依赖图片文件
- 响应式布局，兼容手机 / 平板 / 桌面

## 部署与合规

- GitHub Pages 部署：详见 `部署指南.md`
- 备案要求：详见 `备案指南.md`

> ⚠️ **本站不能使用个人备案**。内容属于企业经营宣传（产品展示、询价引导、联系方式、经营数据），
> 个人备案的适用范围仅限非营利个人网站，提交必被驳回。正式上线需用**个体工商户或公司营业执照**
> 做单位备案，并托管至中国大陆服务器。
